kInorA stands on work that is not its own. This document records what was reused, under which terms, and where the boundary of authorship lies.

## 1. The method and its tooling

**[gentle-ai](https://github.com/Gentleman-Programming/gentle-ai)** — by **Alan Buscaglia**, known in the community as *Gentleman Programming*, on GitHub as [@Alan-TheGentleman](https://github.com/Alan-TheGentleman) and through the [Gentleman-Programming](https://github.com/Gentleman-Programming) organisation. Written in Go, published under the MIT licence.

Four things that the method chapter of this project describes were **adopted, not designed here**: phase-based orchestration with an isolated context window per phase, the explicit criteria for delegating to a subagent, the skill registry that generates `.atl/skill-registry.md`, and the Judgment Day blind adversarial review agents. **Engram**, the cross-session memory protocol from the same author, provides the persistence that lets decisions survive between sessions and across tools.

Building those four pillars from scratch would have been a project in itself, probably larger than kInorA. Without them this work would have been considerably harder to complete in the time available. That it is published under MIT and maintained in the open is what makes it possible for an academic project to rest on it and say so.

What belongs to this project is how that scaffolding was governed: the `AGENTS.md` contract, the seven automated guards, the mode-aware coverage gate, and every product and architecture decision recorded in `openspec/`.

**OpenCode** was the agent environment the work ran in. **Open Design** served as the visual source of truth, consumed over MCP.

## 2. Exercise catalog media

The thumbnails and animations in the exercise catalog are the property of **[Gym visual](https://gymvisual.com/)** and are redistributed under their terms. **They are not covered by this project's licence.**

They reach the product through the dataset [`hasaneyldrm/exercises-dataset`](https://github.com/hasaneyldrm/exercises-dataset), pinned to an immutable commit so the bytes served cannot change without a reviewed update. Thumbnails are self-hosted under `apps/web/public/exercises/`; the animations are served from a CDN, pinned to the same commit, purely to keep roughly 123 MB out of the Docker image.

The full terms, the per-asset delivery table and the upstream notice are reproduced in [`apps/web/public/exercises/ATTRIBUTION.md`](../apps/web/public/exercises/ATTRIBUTION.md), which is generated by the import script and must not be edited by hand.

## 5. Licensing status of this repository

**This repository has no `LICENSE` file yet.** That is a pending decision, not an oversight to leave standing: without an explicit licence the default is "all rights reserved", which is a legitimate choice but should be a deliberate one, and it sits awkwardly next to a project that redistributes third-party media and rests on MIT-licensed tooling.

Whatever licence is chosen must preserve the Gym visual terms for the catalog media, which remain outside its scope in any case.
